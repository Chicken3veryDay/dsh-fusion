# SDK 查询命令定义

[English](guide.md) | 中文

## 变更

显式配置 `queryCommandDefinitions` 的 SDK 部署中，只要接收 Agent 的命令注册表缺少任一配置的定义，斜杠查询就会失败，包括作用域替换导致的缺失。此前这些查询可能成为普通模型提示词。配置额外定义但缺少命令服务时，斜杠查询也会失败。普通非斜杠提示词及使用默认空列表的部署保留原有行为。

## 迁移

1. 检查 SDK 配置覆盖文件中的 `queryCommandDefinitions`，确保与已加载插件提供的命令定义 id 一致。
2. 加载缺少的命令插件或移除不可用 id。确保作用域替换保留预期的定义 id。
3. 提交预期的斜杠命令，确认收到命令结果且未发起普通模型请求；配置错误会指出缺少的定义或服务。
